## Disposition

No hidden actual-state input or unsound certification path was found in the
reviewed deployed M1/M3 scheduler, exact reference or accepted recovery path.
No change to the frozen method or additional benchmark is recommended. The
major limitation is scientific: the primary experiment structurally reduces to
truthful evaluation of a conjunction and cannot demonstrate a recovery-sensitive
advantage from changing the order of disjoint necessary observation groups.

## 1. Primary findings are certificate-acquisition controls

observations.py:51 starts every episode at its validated nominal checkpoint
state. Missing and structured regimes only remove readings (59–68); delayed
readings invalidate the written atoms (69–83), leaving a sound partial view of
the same nominal state. Actual world transitions occur only in the external
invalidation regime (84–101). Noise changes reports, not the nominal world
(103–110). Thus complete/missing/structured/delayed nominal continuations are
valid by construction. The primary subset contains no genuinely invalid nominal
suffixes under accurate sensing.

This has a precise standard explanation. benchmarks.py:_model supplies only
static/equality unit constraints for these domains. Dynamic observations are
partitioned into disjoint predicate-kind groups; a fixed deterministic STRIPS
continuation has a conjunctive regressed obligation. On a valid world, every
unknown necessary group must be acquired to certify that conjunction. Each query
resolves its entire group. M1 and M3 therefore both make min(B,k) additional calls
and certify iff B >= k, where k is the number of unresolved necessary groups.
Changing priority can change query order but not this success/count endpoint.

This is classical conjunction/Boolean-function evaluation, not a new theorem.
It supports an informative Case-B explanation if exact agreement is observed,
not a field-wide claim that recovery-aware priorities never help. Even a blind
always-continue strategy would face no true invalid nominal actions in this
accurate subset, so zero observed current-action errors here cannot establish
empirical safety discrimination. Unit counterexamples and conditional symbolic
proof obligations remain separate evidence. Do not add new faults post hoc.

## 2. Runtime inputs and priority are legitimately separated from evaluator truth

methods.py receives Context and a sensing callback; the context excludes actual
state, future outcomes and regime labels. experiment.py supplies sensor responses
only for the query named by the scheduler; oracle_state is used afterwards for
metric evaluation. The common context hash is checked after each method.

M3's priority is frozen nominal-plan metadata, not estimated from held-out
outcomes. benchmarks.py:_consequence begins at signed START support edges matching
regressed obligations, follows only causal (condition-bearing) edges and counts
remaining action descendants. It does not simply count predicate-name mentions.
Its nominal support graph can be constructed from the validated reference plan
and its regressed precondition witness; it is not the disturbed actual state.
M1/M3 share candidates, exact certification, sensing and recovery. The
M3_no_consequence code path restores M1's count-per-cost score exactly.

This score is a proxy for causal consequence, not measured recovery cost, a
learned risk score, or an optimal value-of-information calculation. Report it
accordingly. No actual-state leak was found in this implementation path.

## 3. M0 comparison has a deliberately different decision obligation

methods.py:90–109 invokes unmodified upstream state_gate on the current action's
preconditions, with common cumulative evidence and all declared dynamic atoms
tracked. Upstream graph.py:build_graph builds incoming condition edges from those
same preconditions, so omitting an explicit incoming-edge union in this checkpoint
projection does not remove additional required literals for the generated graphs.
Resource scheduling, post-action support checks and repeated embodied monitoring
are outside this projection, as the protocol states.

M0's global-unknown blocking is preserved. No batch-overwrite disadvantage is
manufactured: cumulative previously valid readings are returned by the adapter.
M0 uses the fixed periodic view schedule because upstream observe has no query
argument. This adapter is not the published original embodied runtime.

M0 permits a current action; M1/M3 certify a whole fixed retained suffix. A
current-safe/suffix-invalid decision is not an incorrect current-action
permission. experiment.py:59–89 correctly computes separate selected-first-action
and selected-continuation outcomes. Any M0-to-M1 improvement is not pure evidence
allocation efficiency, and none establishes M3's incremental contribution.

## 4. Recovery soundness and one documentation precision correction

The focused second reviewer found no hidden oracle input or unsound acceptance
path. recovery.py accepts only evidence and the common action library, requires
known preconditions during search, validates the complete repaired continuation,
and rechecks its universal validity before returning success (146–154). A planner
can miss a plan whose preconditions follow only via CNF implications because the
upstream State.holds check does not derive those implications. This is conservative
incompleteness, not false permission.

Concrete cap precision: stats['expanded'] is initialized once per recover call
(65), and checked by every Planner.plan invocation (74). Therefore the 2,000
expanded-node limit is aggregate across repair rounds, whereas the 0.10 CPU-second
limit resets per planner attempt. The protocol's 'per attempt' phrasing can be
read more broadly. Record the implemented aggregate expansion cap; do not alter
the sealed algorithm. It applies identically to every method.

semantics.py rejects inconsistent evidence before permission. Decision-state
constraints are intentionally not post-action invariants; the protocol explicitly
states this. No unconditional physical guarantee follows from this finite model.

## 5. Measurement names requiring narrow interpretation

* experiment.py:104–105 sets detection_delay_queries to query count whenever the
  final verdict is INVALID/CURRENT_INVALID. It does not restrict the statistic to
  actually invalid, initially UNRESOLVED supports. Reporting it as that stronger
  secondary detection-delay endpoint requires filtering/recomputation. Otherwise
  describe it simply as calls before an invalidity verdict.
* recovery_success means a certified repair sequence was returned. Actual goal
  satisfaction is goal_completion. These can differ under noisy/stale evidence.
* evidence_covers_truth is initial-K coverage (67–70), not final evidence coverage.
  The independent audit separately computes final-K coverage.
* irrelevant_atom_reads is a relevance-closure diagnostic conditional on evidence,
  not a proof that observing a known but stale atom has no value. The separate
  relevance audit distinguishes known reads and immediate query value; do not
  turn a zero immediate-value result into global policy irrelevance (XOR is a
  counterexample).
* False-permission metric means in analysis are per attempted decision, with
  parent-instance weighting. Permission denominators are also retained; say which
  denominator a reported rate uses. Abstention is not counted as false permission.
* valid_continuation and goal_completion coincide by the selected open-loop
  sequence/goal definition. They are not two independent success confirmations.

The two omitted Logistics qualification tasks are recorded planner timeouts, not

robotics generalization. Public IPC tasks with ideal symbolic channels are not
ALFWorld comparative execution or embodied validation. No manuscript or
publication-level novelty conclusion is warranted from this implementation alone.

No significant difference is not equivalence. If primary M1/M3 differences are

model was disproved. A claim of unconditional true-state safety would nonetheless
be false under those stress assumptions.

[-0.011905,0.041667]. This is outside the primary endpoint, below the declared

Across all four budgets in that stress (672 attempted decisions per method),
M3 has 90 false current-action permissions and 101 invalid continuation
permissions; M1 has the same counts. Goal completions are 136 for M3 versus 130

under the 14 parent tasks, not 672 independent trials.

In noise05, M1 and M3 each have 24 false current-action permissions, 24 invalid
continuation permissions, 456 completions and zero queries among 672 attempts.

limitation of that loop. M0 has 4 false current permissions and 624 completions
in the same noise condition, with a different current-action gate contract.
Do not claim that checking more nominal obligations automatically improves
true-state reliability under corrupted evidence.
