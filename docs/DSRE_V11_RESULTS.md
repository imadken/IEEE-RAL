## Exact finite observability ceiling

For an exact observed signature z, a universally adequate deterministic decision
must belong to every associated Good set. If the intersection is empty it cannot
act; otherwise choosing any common action attains the finite-table bound. Thus
`C_max=sum N_z*1[G(z) nonempty]/N`. This is an elementary finite characterization,
not a new theorem or deployment/population ceiling. Independent exhaustive action
and conjunction checks agree on all38 observed groups across six profiles.

Entries below give **signature count / checkpoint mass**. Inadequacy means a class
contains at least one neither-success row, not that every row in that mass fails.
Ambiguity requires nonempty disjoint action sets. The two causes can overlap.
