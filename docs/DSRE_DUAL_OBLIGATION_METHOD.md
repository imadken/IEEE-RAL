# DSRE: two distinct recovery obligations

This is a separate evaluator of the frozen DSRE/B7 and CART2 proposals. It does
not replace strict DSRE adequacy, its minimum-literal solver, the original
success-risk gate, the seven observable facts, or either fixed intervention.
The original source-risk study remains an immutable primary historical result.

For paired terminal flags C,R in {0,1}, the four outcomes are C-only, R-only,
both-success and neither-success. An absolute recovery error is `not R`.
A binary task-outcome degradation is `C and not R`. A futile rescue attempt is
`not C and not R`. Absolute failure is the disjoint union of degradation and
futility at a checkpoint. This elementary identity is not a new theorem.
Non-degradation can hold when both interventions fail; it is neither task
completion nor robot safety, collision avoidance, energy efficiency or low cost.

Each independent seed parent has five correlated offset conditions. For a
frozen method/action proposal, a parent is assigned when any condition proposes
that action. An assigned parent is erroneous if any assigned condition violates
the chosen obligation. Thus checkpoint events are disjoint, but their parent
unions may overlap: parent absolute error is `any harm OR any futile attempt`;
the difference of parent risks counts futile-error parents without a harm error.
Five conditions never create five independent calibration trials.

The preregistered family is exactly these six one-sided claims:

| Router | Action | Error |
|---|---|---|
| DSRE risk | recover | R=0 |
| DSRE risk | recover | C=1,R=0 |
| DSRE risk | continue | C=0 |
| CART2 risk | recover | R=0 |
| CART2 risk | recover | C=1,R=0 |
| CART2 risk | continue | C=0 |

All target 10%, with exact Clopper–Pearson upper bounds and Bonferroni
delta=0.05/6. A zero-error stratum needs at least 46 assigned independent
parents. Zero assignments and incomplete 256-parent calibration disable the
claim. Alpha is never reallocated. B7 shares DSRE's verdict by exact identity;
fixed actions are descriptive and receive no new certification.

Two prospective compositions apply to the same frozen proposals. The absolute
composition permits C or R only if its new absolute bound qualifies. The
non-degradation composition uses the same continue requirement and permits a
proposed recovery if its new non-degradation bound qualifies. Disabled
proposals STOP; they are never rerouted. Both are sealed for the full test
cohort before any test future is opened. Display statuses are
`ABSOLUTE_SUCCESS_QUALIFIED`, `TASK_NONDEGRADATION_QUALIFIED_ONLY`, or
`UNQUALIFIED`. An annotation never changes the original task-adequacy status.
No new minimum-evidence optimization for the harm endpoint is performed or
claimed. The original minimum-evidence packets and witnesses remain unchanged.

The original historical gate is also retained byte-for-byte. The unchanged
collector expects its legacy file schema, so that file is copied only as a
transport/descriptive comparator. Its old 34 strata are not recalibrated,
allocated new alpha, or claimed to transfer. New qualifications exist only in
`dual_calibration.json`, with the independent six-claim audit alongside it.

Required recovery is an initially unsuccessful R-only checkpoint. Initially
successful R-only cases are preventive and are reported separately. Completion
credits selected successful physical branches; STOP receives zero. Report
recovery attempts, harmful recoveries, futile attempts, both-success
maintenance, conditional success, coverage, abstention and completion. The
separate futile-cost statistic is a count/rate of attempted recoveries and their
fixed 70 controls, not an invented time, energy or damage utility.

All methods use identical physical pairs reconstructed from reset and the full
canonical prefix, with qualified controller/RNG/model/contact/state parity.
No method receives an additional useful prefix. The selected branch inherits
the same matched-state action-execution guard; no extra selected-action physics
or independent statistical replicate is introduced.

Grouped paired uncertainty uses 4,000 PCG64 resamples, seed 2026111603, retaining
all conditions within each parent and keeping cohorts separate. Test intervals
are descriptive; they never change eligibility or add new risk claims. Finite
seven/twelve-fact observation partitions, true action infeasibility and frozen
reference witnesses remain distinct from population risk. No clean certificate
transfers to corrupted inputs or outside the registered simulator distribution.
