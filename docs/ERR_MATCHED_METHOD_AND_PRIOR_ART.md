All controls receive identical known likelihoods, finite world catalogues, type
costs, source assumptions and target verdicts. The exact solver is independently
checked by exhaustive subsets and a separate integer program. The latter is
not trusted outside its explicitly representable integer-cost range.

For actual source witnesses, D/C-only processes compare the complete original
DSRE/B7 certificate and the augmented contextual outputs, including bounds,
region, source, explanation, plan and withholding interpretation. The existing
Boolean scope grammar is also checked exhaustively. Algorithm-specific runtime
and internal state counters are not scientific differences. The same processor
is deliberately shared; equality is expected and must not be marketed as a win.

In the declared seven-world example, unpruned greedy costs 6 while exact costs
4. Reverse-deletion greedy also costs 4. In the 504 seeded cases, exact and
unpruned greedy have equal cost in 377 of 440 resolvable instances; pruning
raises this to 431/440. The other 64 are impossible for all methods under the
declared menu. These are synthetic optimizer diagnostics. There is no evidence
of a physical action-execution saving. The original grasp acquisition study
with a common512-outcome base and512 added outcomes remains a five-strategy tie.

## Stronger antecedents found by the independent challenge

The supplied list is not the whole novelty boundary. Three additional primary
sources materially constrain the general methodological claim:

- [Golovin, Krause and Ray, Section3](https://las.inf.ethz.ch/files/golovin10near.pdf)
  already define equivalence-class determination: select costly tests to decide
  which hypothesis class contains the truth. Opposite-verdict edges are an
  established construction. Their adaptive finite-observation/noise objective
  differs from this nonadaptive ideal-law type cover, but class-specific
  information acquisition is not new.
- [Chen et al., AAAI2015, primary abstract](https://ojs.aaai.org/index.php/AAAI/article/view/9694)
  develops value-of-information/decision-region methods and evaluates robotic
  touch localization. Thus merely applying decision-relevant information
  gathering to a robot is not a new robotics contribution. The particular
  causal harm/source contract would have to carry the scientific distinction.
- [Healy and Leo, SectionVIII, pp28–30 of the author manuscript](https://healy.econ.ohio-state.edu/papers/Healy_Leo-Minimal_Experiments.pdf)
  explicitly forms distinguished model-type pairs, identifies separating
  experiments and solves a costed binary set cover. The journal version is
  [2026, DOI10.1016/j.jet.2026.106191](https://doi.org/10.1016/j.jet.2026.106191).
  Preference-specific structure differs from robot joint outcomes, but the
  generic minimum distinguishing-experiment mechanics are already present.

The finite ERR cover can be passed unchanged to a standard weighted-cover
solver once its source laws and verdict classes have been constructed. The
declared recovery world model and provenance conventions give an application
contract, not a newly established general experiment-design principle.

## Scientific novelty decision

**Implemented functional addition:** yes. Certificate-only DSRE now has an
explicit finite-model minimum experiment/counterexample output alongside its
unchanged authorization object. It is independently verified and has a
source-grounded recorded-fact capability demonstration.

**Unique optimizer, witness algorithm, generic experiment-identification or
first robotic information-design contribution:** not established. The fully
instrumented B7 implementation is equivalent, and the strongest generic
mechanics have direct prior antecedents. No new physical paired-only regime,
complete robot population world catalogue, acquisition saving or sensing
improvement has been demonstrated in this no-physics session.

**Current gate: METHOD_EQUIVALENT_AND_NOT_DISTINCTLY_MOTIVATED.** This is a
technical-originality judgment in the checked scope, not a claim that the
recovery-evidence question is useless or could never support a worthwhile
application study. Passing exact implementation tests is not evidence that the
selected extension clears the supervisor's scientific-distinction requirement.
The present evidence supports a transparent finite-model prototype and a
falsifiable application hypothesis. It does not justify silently promoting the
generic cover mechanism to a new robot methodology in the Stage1 abstract.

The next phase is supervisor-led paper preparation using these verified limits,
not a new scientific direction or an unbounded search for a favorable task.
